# PostService Вебзастосунок

## Запуск із вихідного коду

Потрібен .NET SDK 10. З кореня репозиторію запустіть:

```powershell
dotnet run --project PostServiceSolution/PostService --no-launch-profile
```

Відкрийте [вебзастосунок PostService](http://localhost:5036/). Один процес обслуговує вебінтерфейс і REST API. Під час першого запуску сервер створює локальну базу SQLite. Параметр `ConnectionStrings__Postings` дозволяє вказати шлях до окремої бази.

## Запуск збірки Windows x64

Потрібен ASP.NET Core Runtime 10 для Windows x64. Розпакуйте архів, відкрийте його папку в терміналі й запустіть `./PostService.exe`. Відкрийте адресу `http://localhost:5036/`.

## Демонстрація

1. З головної відкрийте «Про програму», а потім «Відправлення» через верхнє меню.
2. Натисніть «Нове відправлення» й спробуйте зберегти порожню форму. Поля з помилками отримають рамку, значок і текстову підказку.
3. Заповніть відправника, отримувача та вміст. Для експрес-доставки вкажіть фактичну вагу 5 кг і габарити 20 × 40 × 30 см. Форма покаже розрахункову вагу 6 кг і вартість 180 грн. Збережіть запис.
4. Відкрийте «Деталі», поверніться до списку й відкрийте «Редагувати». Змініть фактичну вагу на 7 кг і збережіть. У списку з’явиться вартість 210 грн. Ще раз відкрийте редагування та перевірте «Скасувати».
5. Звузьте вікно до 390 px. Список перебудується в картки, а підказки форми з’являтимуться під полями.
6. Натисніть «Видалити» й підтвердьте дію в діалозі. Запис зникне зі списку.
